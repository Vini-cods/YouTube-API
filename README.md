##  YouTube Video Search App (React Native + YouTube API)

This is a simple mobile application built with React Native using the YouTube Data API. The app allows users to search for videos and display them inside the app using a WebView.

## 🔑 API Key

You will need a **YouTube Data API v3** key from the [Google Cloud Platform](https://console.cloud.google.com/).

Replace the `SUA_CHAVE_API_YOUTUBE` placeholder in `youtube.js` with your actual API key.

## 📚 Dependencies

- [axios](https://www.npmjs.com/package/axios)  
- [react-native-webview](https://www.npmjs.com/package/react-native-webview)

Install them using:

```bash
npm install axios react-native-webview
